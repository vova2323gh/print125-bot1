# Dorm Print Bot v2

`/admin` — адмін-панель. Є нові/в роботі/виконані замовлення, статистика, зміна цін та розсилка.

Команди: `/setbw 3`, `/setcolor 5`.

Запуск: `py -m venv .venv` → `.venv\Scripts\activate` → `pip install -r requirements.txt` → `python bot.py`.

Не публікуй `.env`: там токен бота і номер картки.


### Антиспам
Користувач може мати максимум 3 незавершені замовлення. Кнопка нового замовлення має короткий захист від багаторазових натискань. Перед створенням кожного замовлення ліміт перевіряється повторно.
